# 美而美 POS · 點餐工作台

網站：https://martyli.github.io/mei-er-mei-pos/

給早餐店櫃檯使用的繁體中文單機網頁 POS。介面參考 iCHEF 公開介紹的「訂單與菜單同畫面、點餐 → 客製 → 結帳、前台與設定分開」流程，以原創視覺與模組實作。並非 iCHEF 的內部系統或官方產品。

## 使用方式

- 點餐點名稱開啟客製；點卡片「＋」直接加入原味。
- 預設加料：加蛋 +$15、起司 +$10、肉鬆 +$10。可複選，每份都計入加料費。
- 訂單列可修改加料、備註、份數。不同組合獨立列出，相同組合合併。
- 支援外帶、內用桌號、整單備註及暫存。取回暫存時，正在編輯的非空訂單會自動暫存。
- 現金結帳輸入實收，顯示不足或找零；確認後記錄交易並建立下一單。
- 「交易」可查日期、營業額、餐點排行、明細及匯出 CSV。列印內容是交易明細，非統一發票。
- 「設定」可管理餐點、分類、加料名稱與價格、販售狀態；每道餐點可指定適用加料。
- 「設定 → 資料備份」匯出完整 JSON，換裝置時可以還原。

## 資料與相容性

使用目前瀏覽器的 localStorage 儲存，不會跨裝置自動同步。請用固定的正常瀏覽器視窗，建議每天收店下載備份。清除網站資料或瀏覽器資料會移除本機記錄。

首次使用新版會將舊版 `mei-er-mei-menu-v1`、`mei-er-mei-addons-v1` 轉成 v2，保留原菜單與加料價格，並保留舊儲存鍵。舊版未持久化的訂單無法轉移。餐點預設都可加料，飲料預設不提供，可在設定逐項調整。

訂單使用價格快照：修改菜單不回寫目前訂單、暫存與歷史交易的原價。所有金額使用新台幣整數。每列最多 999 份，單項價格 0～99,999 元。

本版提供單機現金記帳，沒有金流、電子發票、廚房連線、員工權限、退款或雲端同步。頁面首次載入需網路；不承諾關閉後可離線重新開啟。多分頁同時作業會提示重新載入，建議只開一個點餐分頁。

## 程式結構

| 檔案 | 責任 |
| --- | --- |
| `index.html` | 語意頁面入口與模組載入 |
| `styles.css` | 電腦、平板、手機與列印排版 |
| `app.mjs` | 畫面、表單、互動、匯出與使用者提示 |
| `core.mjs` | 計價、訂單生命週期、交易快照、每日統計與資料驗證 |
| `storage.mjs` | 舊資料轉換、本機儲存、完整備份還原及多分頁衝突檢查 |
| `core.test.mjs` | Node 原生測試，不需額外套件 |

儲存流程：複製狀態 → 套用變更 → 驗證 → 寫入單一 JSON → 更新畫面。寫入失敗時保留前一狀態，不會誤顯示結帳成功。啟動遇到毀損資料會提供原始資料匯出，不自動清空。

靜態 ES modules，無外部套件或追蹤。將上述網站檔案放在 GitHub Pages 根目錄即可部署。用 HTTP/HTTPS 靜態伺服器開啟，不以檔案協定直接開啟。

執行核心測試（Node.js 22 以上）：

```sh
node --test core.test.mjs
```

11 項測試涵蓋菜單轉換、加料與份數、編輯合併、暫存切換、現金驗證、臺北日期換日、儲存失敗、多分頁衝突、有效/無效備份，以及毀損資料保留。另以瀏覽器檢查點餐、結帳、設定保存，及 390px 手機 / 1024px 平板排版。
